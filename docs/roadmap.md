# Rune Cast implementation roadmap

For the detailed task sequence, asset preparation, dependencies, completion criteria, and separate-chat handoffs, use the [master project plan](project-plan.md). This roadmap remains the milestone summary; update its checkboxes as the corresponding planned work is completed.

## Foundation

- [x] Preserve and document the approved visual references.
- [x] Pin and bootstrap the Godot editor.
- [x] Configure a portrait GDScript project.
- [x] Implement circuit validation and evaluation.
- [x] Implement a repeatable training encounter.
- [x] Support rune installation, techniques, draw/discard, and temporary runes.
- [x] Implement Menu, Guide, and Sound controls.
- [x] Include a Map placeholder that identifies its current status.
- [x] Prepare Android and iOS export presets.
- [x] Add rule checks and runtime verification.
- [x] Document open decisions and the asset plan.

## First playable content milestone

- [ ] Test whether players voluntarily reshape a working circuit.
- [ ] Test effect persistence against one-cast effect runes.
- [ ] Add a small set of hand-designed boards and enemy intent patterns.
- [ ] Add clear mobile rune inspection and placement feedback.
- [ ] Replace the enemy, environment, and UI placeholders with approved assets.
- [ ] Add attack, hit, shield, and victory feedback.
- [ ] Test on physical Android and iOS devices.

## Short run milestone

- [ ] Build branching routes, encounter rewards, and rune collection.
- [ ] Implement saving and resuming between encounters.
- [ ] Add shops, recovery rooms, events, and a final guardian.
- [ ] Add relics and upgrades after the core balance is stable.
- [ ] Test the 15–25 minute run target.

## Release preparation

- [ ] Confirm studio name, application identifiers, signing, and store accounts.
- [ ] Configure matching export templates and platform SDKs.
- [ ] Complete notch/safe-area, accessibility, suspend/resume, and performance testing.
- [ ] Finalize original art, audio, credits, and asset licences.
- [ ] Produce signed builds and store materials.
