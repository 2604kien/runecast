# RC-018 r001 historical source archive

The owner rejected this procedural sound direction as resembling modified snares. It is retained for historical evidence and comparison, not current production selection.

This directory contains the original 21 runtime WAVs, their matching 24-bit masters under `masters/`, and the original settings, generator, generation measurements and provenance. `delivery-r001.txt` and `family-deliveries/*.txt` preserve the dated delivery text verbatim; their old relative links describe the original directory layout. Original QA records are retained under [output/qa/rc-018/r001](../../../../../output/qa/rc-018/r001/).

The [historical r002 comparison](../../../../../output/audio/rc-018/r002/index.html) references these frozen WAVs. Current source selection and regeneration instructions are in the [active delivery](../../delivery.md). Run the active Runway renderer for current runtime exports.
